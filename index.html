สำรวจสายสื่อสารบนเสา
สำรวจตามแนวเสา: จุดที่ 1 เก็บรายละเอียดสายทุกเส้น → จุดถัดไป สายที่ค้างอยู่จะถูกนำมาให้ เลือก "ผ่านต่อ" หรือ "สิ้นสุดที่เสานี้" → จุดสุดท้าย จบการสำรวจ
✓ ระบบบันทึกงานค้างอัตโนมัติในเครื่อง และสำรองไป Supabase เพื่อกู้คืนได้หากปิดระบบกะทันหัน
คลี่สาย
แก้ไขเส้นทาง
เลือกเส้นทางเดิมเพื่อแก้ไขรายละเอียดและแนวสายโดยตรง การต่อจากต้นทาง/ปลายทาง การดึงเสาออก หรือย้ายเข้าเสาอื่นจะบันทึกทับแถวเดิม ไม่สร้างรายการเส้นทางใหม่
ลากเส้นทางพาดสาย
แตะ หมุดเสา (จุดเหลือง) ตามลำดับที่สายพาดผ่าน เสาที่เลือกจะเปลี่ยนเป็นสีฟ้า — แตะเสาสีฟ้า เพื่อแก้ไข (เอาออก / ย้ายไปเสาอื่น / ตัดหัว-ท้ายเส้น)
เครื่องมือเส้นร่าง: ร่างเส้นอิสระ (ไม่ต้องแตะเสา ลากจุดได้ทุกที่) → กด นำเข้าแนวเสา เพื่อให้ระบบจับเสาตามแนวเส้น หรือกด ดึงออกจากแนวเสา เพื่อแปลงเส้นที่เลือกเสาแล้วเป็นเส้นร่างที่ลากแก้ได้
ยังไม่ได้เลือกเสา▲
แตะแผนที่เพื่อปักหมุดตำแหน่งเสา

เลือกรายชื่อเสาเพื่อดูรูปที่บันทึกไว้ของ TAG นี้
หมายเหตุ
พาดสายบนเสา — เครื่องมือเส้นร่าง
ร่างเส้นอิสระ (ไม่ต้องแตะเสา) → นำเข้าแนวเสา เพื่อจับเสาตามแนวเส้น หรือ ดึงออกจากแนวเสา เพื่อแปลงเส้นที่เลือกเสาแล้วกลับเป็นเส้นร่างที่ลากแก้ได้ (ตั้งชื่อ/เจ้าของ/ประเภทสาย และบันทึก KML ได้ที่แผง "ลากเส้นทางพาดสาย")
กล้องความละเอียดสูงสุด Timestamp
ปุ่ม Timestamp: ปิดลายน้ำเดิม/ทำตัวหนังสือและพื้นหลังให้โปร่งใสก่อนถ่าย ระบบจะใส่ข้อความรูปแบบใหม่ให้เอง
📷นำรูปจาก Timestamp Camera
